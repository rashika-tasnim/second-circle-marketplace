# Second Circle

A full-stack marketplace for discovering, saving, listing, and discussing pre-owned items.


Visitors can browse the catalogue without an account. Registration is required to save items, publish a listing, or contact a seller.

## Features

- Email registration, confirmation, login, and logout
- Search, category browsing, and multi-criteria filtering
- Detailed item pages and persistent saved items
- Authenticated listing creation with image upload
- In-app contact messages between buyers and sellers
- Personal inbox, saved-items area, and listing management
- Ownership-based access controls and protected user data
- Responsive desktop and mobile interface

## Technology

- Next.js and React
- TypeScript
- Supabase Authentication
- PostgreSQL with row-level security
- Supabase Storage
- Responsive custom CSS
